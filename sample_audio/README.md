These are individual test clips selected from the local comparison set with source metadata marked CC0 1.0. They are provided for a small demonstration, not as the complete training, validation, or test dataset. They retain their original audio IDs. The full dataset must be obtained or rebuilt following [the dataset guide](../documentation/dataset.md).
